# Web accessibility

- Make every interactive element reachable by keyboard and give it a visible focus indicator.
- Give every form control a label tied to it by `for`/`id` or by nesting.
- Give meaningful images descriptive `alt` text and decorative images `alt=""`.
- Use a text contrast ratio of at least 4.5:1, or 3:1 for large text.
- Prefer native `<button>` and `<a>` elements to custom elements with accessibility roles.
